# Party-Feud

### A fun, live game for parties inspired by Family Feud. Designed for groups to play in-person or online using just a projector or shared screen. Perfect for game nights, classrooms, or team events.

---

## 🧩 Prototype Version Features

* Answer panel reveals responses on click and automatically tallies round score.
* Game master can add points to the winning team and advance to the next round.
* Sound buttons included for the classic theme and winning team jingle.
* Visual indicator for incorrect answers (strikes).
* Control buttons at the bottom for:
  * Advancing to next round
  * Resetting the current round
  * Resetting the entire game
* Questions and answers are currently customizable via the `data.js` file.
* No home screen yet — game starts directly on a blank question board.
